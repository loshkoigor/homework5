# Домашнее задание №5

**Название:** Вычисление функции и проверка условий (вариант 14)

**Автор:** Лошко Игорь Сергеевич, бТИИ-261

**Описание:** Программа запрашивает число `x` и вычисляет значение функции `g` по формуле варианта 14 через промежуточные величины `a` и `b` (`g = a + b`), где `y = 15.4` и `z = 0.252e3` заданы константами. Результат выводится с точностью до 6 знаков после запятой (контрольный пример: `x = 1.23`, `g = 82.825623`). Затем для целых частей `A`, `B`, `C` величин `a`, `b`, `g` проверяются условия: а) только одно из чисел `A` и `B` чётное; б) каждое из чисел `A`, `B`, `C` кратно трём. Результат каждого условия выводится как 1 или 0. Блок-схема алгоритма - в файле `blok_shema.png`.

**Компиляция:** Проект создан в Visual Studio 2022. Для сборки нажмите Build Solution.
